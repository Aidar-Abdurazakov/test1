AIOGRAM — ОСНОВЫ TELEGRAM-БОТА

from os import getenv
→ импортируем getenv из os. getenv нужен, чтобы получить значение переменной по её названию.

import asyncio
→ подключаем asyncio для работы с асинхронным кодом и запуска main().

from aiogram import Bot, Dispatcher, Router
→ импортируем из aiogram три инструмента:
Bot — сам Telegram-бот.
Dispatcher — получает события от Telegram и передаёт их дальше.
Router — помогает организовать обработчики сообщений.

from dotenv import load_dotenv
→ импортируем функцию для загрузки данных из файла .env.

load_dotenv()
→ загружаем данные из .env, чтобы Python мог их использовать.

TOKEN = getenv("BOT_TOKEN")
→ берём значение BOT_TOKEN из .env и сохраняем его в переменную TOKEN.

dp = Dispatcher()
→ создаём Dispatcher. Он будет получать события от Telegram.

router = Router()
→ создаём Router. Он будет управлять обработчиками сообщений.

dp.include_router(router)
→ подключаем Router к Dispatcher.

@router.message()
→ говорим Router: «сообщения пользователя обрабатывай следующей функцией».

async def hello(message):
→ создаём асинхронную функцию hello. message — это сообщение, которое отправил пользователь.

await message.answer("Hello")
→ отвечаем пользователю сообщением «Hello». await означает: дождаться выполнения этого действия.

async def main():
→ создаём главную функцию, внутри которой запускается бот.

bot = Bot(token=TOKEN)
→ создаём Telegram-бота и передаём ему токен.

print("Start...")
→ просто выводим «Start...» в терминал. Это нужно для нас, чтобы видеть, что программа дошла до этого места.

await dp.start_polling(bot)
→ запускаем бота. Dispatcher начинает постоянно получать новые события от Telegram.

if __name__ == "__main__":
→ проверяем, что файл запущен напрямую.

asyncio.run(main())
→ запускаем главную функцию main() и тем самым запускаем нашего бота.

ГЛАВНАЯ СХЕМА:

Пользователь пишет сообщение
↓
Telegram
↓
Bot
↓
Dispatcher
↓
Router
↓
нужная функция
↓
message.answer()
↓
бот отвечает пользователю


САМОЕ ГЛАВНОЕ:

Bot = сам бот.
Dispatcher = получает события.
Router = направляет события к обработчикам.
@router.message() = обработчик сообщений.
message = сообщение пользователя.
message.answer() = ответ пользователю.
TOKEN = секретный токен бота.
.env = файл, где храним секретные данные.
async = асинхронная функция.
await = ждём выполнения действия.
main() = главная функция запуска.
